# CampusConnect Frontend

Responsive student management system built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure, login, dashboard and management forms
- `css/style.css` — responsive styling
- `js/app.js` — demo login, student CRUD, course catalogue, registrations, validation and browser storage

## Run
Extract the ZIP and open `index.html` in your browser, or open the folder in VS Code and run it with Live Server.

## Important
This is a frontend prototype. Records are saved in the current browser using localStorage, not a shared database. The demo login is not secure. For a coursework Laravel submission, connect these pages to Laravel authentication, routes, controllers, migrations, Eloquent models, validation and a database.
